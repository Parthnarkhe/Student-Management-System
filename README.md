# Student Attendance Management System

## Project Description
The Student Attendance Management System is a mini project developed to manage student attendance records easily. It calculates attendance percentages and helps identify students whose attendance is below 75%.

## Technologies Used
- HTML
- CSS
- JavaScript
- Microsoft Excel

## Main Features
1. Add student attendance records.
2. Calculate attendance percentage automatically.
3. Calculate absent days.
4. Display attendance records.
5. Identify students with attendance below 75%.
6. Delete individual student records.
7. Clear all records.
8. Store records using LocalStorage.

## How to Run the Project
1. Download the project files.
2. Open the `index.html` file in a web browser.
3. Enter student details and attendance information.
4. Click the Add Student button.
5. View the calculated attendance percentage and attendance status.

## Conclusion
This project provides a simple way to maintain student attendance records and calculate attendance percentages. It reduces manual calculations and makes attendance management easier.
